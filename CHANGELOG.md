# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2025-01-XX

### Added

- Initial release of @43x/pptx-parser
- Core PPTX parsing functionality
- Support for text, image, shape, table, chart, audio, video elements
- TypeScript type definitions
- Framework-agnostic design
- Utility functions for font conversion, SVG path parsing, transformations
- Comprehensive documentation and examples
- React example implementation

### Features

- Parse PPTX files to structured JSON data
- Automatic slide scaling and responsive sizing
- Support for backgrounds (solid, gradient, image)
- Element positioning and rotation
- Shadow and outline support
- Custom theme colors

### Dependencies

- pptxtojson: ^3.0.1 - Core PPTX parsing library
